# Brick Breaker Game

A simple Brick Breaker game developed in **C++** using the **SDL2** library.

This project was created as an **OOP assignment** from the Information Management Group (IMG), IIT Roorkee.

## Controls

* **Left Arrow** — Move paddle left
* **Right Arrow** — Move paddle right

## Technologies Used

* C++
* SDL2
* g++

## Project Structure

```text
main.cpp
Constants.h
Colors.h
SDLSetup.h
Paddle.h
Ball.h
Brick.h
README.md
```

## Compilation

Compile the project using:

```bash
g++ main.cpp -o game $(sdl2-config --cflags --libs)
```

## Run

After compilation:

```bash
./game
```
